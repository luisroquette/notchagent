# NotchAgent 3.1.2 — Desk guided setup

NotchAgent 3.1.2 turns the Desk setup into a guided customer flow.

## Install

1. Download `NotchAgent-Desk-Beta1-3.1.2.dmg`.
2. Open the disk image and drag NotchAgent to Applications.
3. Open `Comece aqui` for the PT/EN visual walkthrough.
4. Connect the Desk by USB and complete the official Codex login.

The app and disk image are signed with Developer ID, notarized by Apple, and
stapled for offline Gatekeeper verification. The bundled recovery firmware is
still `0.6.16` using protocol `1.1`.
